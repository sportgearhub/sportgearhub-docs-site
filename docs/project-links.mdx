# Ссылки проекта

Текущая практика в этом репозитории: хранить проектные ссылки в TypeScript-конфиге `src/config/projectLinks.ts`.

Почему так удобно прямо сейчас:

- Одна точка правды в кодовой базе сайта
- Типизация (`ProjectLink`) защищает структуру данных
- Быстро подключается в UI без дополнительной загрузки JSON

## Текущая структура

```ts
export const projectLinks = [
  {
    title: 'docs.sportgearhub.ru',
    url: 'https://docs.sportgearhub.ru',
    description: 'Документация проекта (текущий проект)',
  },
  {
    title: 'sportgearhub.ru',
    url: 'https://sportgearhub.ru',
    description: 'Сайт',
  },
];
```

## Быстрые ссылки

- Документация: https://docs.sportgearhub.ru/docs/intro
- Основной сайт: https://sportgearhub.ru

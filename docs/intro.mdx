# Добро пожаловать в SportGearHub Docs

Это основной портал документации проекта SportGearHub.

## Что здесь хранится

- Гайды для команды и партнёров
- Техническая документация по процессам
- Юридические и организационные материалы

## Быстрый старт

1. Откройте нужный раздел через левое меню.
2. Используйте поиск по сайту для быстрого доступа к страницам.
3. Если нашли неточность, нажмите `Edit this page` и предложите правку.

## Полезно знать

- Основная локаль сайта: `ru`
- Английская версия доступна через переключатель языков в верхнем меню
- Контент синхронизируется из `sportgearhub-docs` при деплое
